# Q3 온디바이스 조류 감지·퇴치 장치의 기술 실현성

조사일 2026-09-09. WebSearch 8회 · WebFetch 22회. 출처 태그는 8개로 제한, 넘친 출처는 「확인 못 한 것」 아래 "보조 확인"으로 내렸다.

### 발견

**(a) 엣지 보드 감지 성능 실측**

1. Raspberry Pi 4/5 + Coral Edge TPU 조합으로 비둘기를 실시간 감지하는 공개 저장소가 있고, 라이브 카메라 처리 속도를 CPU 전용 8.38 FPS, Coral 1개 22.88 FPS, Coral 2개 32.34 FPS 로 보고한다 — 원문: "Raspberry Pi 4 with Coral Edge TPU" / "Raspberry Pi 5 with Dual Coral Edge TPUs" / "8.38 FPS" / "22.88 FPS" / "32.34 FPS" [S1]
2. 같은 저장소의 순수 추론 지연은 CPU(LiteRT) 114.28 ms, Dual Coral 26.35 ms 다 — 원문: "114.28 ms" / "26.35 ms" [S1]
3. 이 저장소는 COCO 로 사전학습·양자화된 SSDLite MobileDet 모델 파일을 그대로 쓴다(별도 학습 없이 새 감지 가능) — 원문: "ssdlite_mobiledet_coco_qat_postprocess_edgetpu.tflite" / "COCO label files" [S1]
4. Coral 경로의 알려진 제약: pycoral 유지보수 중단·Python 3.9 까지만 지원·NumPy 2.0 미만 요구 — 원문: "Google is no longer actively maintaining `pycoral`" / "`pycoral` wheels only support up to **Python 3.9**" / "NumPy < 2.0" [S1]
5. 가속기 없는 Raspberry Pi 5 CPU 에서 YOLO26n(640 입력, FP32)은 NCNN 포맷 67.03 ms/im(mAP50-95 0.4784), PyTorch 포맷 299.09 ms/im 이며 전·후처리는 제외한 값이다 — 원문: "Benchmarks were run on a Raspberry Pi 5 at FP32 precision with default input image size of 640." / NCNN 행 "9.4 | 0.4784 | 67.03" / PyTorch 행 "5.3 | 0.4760 | 299.09" / "Inference time does not include pre/post-processing." [S2]
6. XIAO ESP32S3 Sense(ESP32-S3 급 MCU)에서 Edge Impulse FOMO(MobileNetV2 0.35, 96×96 입력)는 추론 143 ms·약 7 fps, RAM 약 250KB·Flash 80KB 로 돈다 — 원문: "the model latency is 143ms, and the frame rate per second is around 7 fps" / "This model uses around 250KB of RAM and 80KB of ROM (Flash)" / "FOMO (Faster Objects, More Objects) MobileNetV2 0.35" / "resizing the individual images from 320 x 240 to 96 x 96" [S3]

**(b) 데이터셋·소량 학습**

7. COCO(330K 이미지, 80 클래스)에 `bird` 클래스가 포함돼 있어, COCO 사전학습 검출기는 추가 학습 없이 새를 검출한다 — 원문: "COCO contains 330K images, with 200K images having annotations for object detection, segmentation, and captioning tasks." / "14: bird" / "Train2017: 118,287 images for training object detection, segmentation, and captioning models." [S8]
8. FOMO 예제는 라벨 47장으로 시작해 F1 85%(테스트 83%)를 얻었다 — 소량 데이터 전이학습이 MCU 급에서도 동작한 실측 — 원문: "All the not-labeled images (47) were uploaded" / "the model ends with an overall F1 score of 85%, similar to the result when using the test data (83%)" [S3]

**(c) 저전력 트리거 → 카메라 추론 구조**

9. ESP32-S3 딥슬립은 CPU·RAM 대부분·APB 디지털 주변장치를 끄고, RTC GPIO 레벨(ext0/ext1)·타이머·ULP 로 깨울 수 있다 — PIR/mmWave OUT 핀을 RTC GPIO 에 물려 웨이크업하는 구조의 공식 근거 — 원문: "In Deep-sleep mode, the CPUs, most of the RAM, and all digital peripherals that are clocked from APB_CLK are powered off." / "The RTC IO module contains the logic to trigger wakeup when one of RTC GPIOs is set to a predefined logic level." / "ULP coprocessor can run while the chip is in sleep mode, and may be used to poll sensors, monitor ADC or GPIO states." [S4]
10. HLK-LD2410 은 24GHz mmWave, 최대 5 m·거리 분해능 0.75 m, 5~12V 전원, GPIO·UART 출력이며 벤더는 **사람** 존재 감지용으로 규정한다(새 감지 검증 없음) — 원문: "24GHz millimeter wave radar sensor" / "The longest sensing distance is up to 5 meters" / "distance resolution is 0.75m" / "5～12V wide voltage power supply" / "Support GPIO and UART output" / "identify human bodies in motion and stationary states" [S5]

**(d) 퇴치 액추에이터 부품·전원**

11. 12V 플라스틱 물 솔레노이드 밸브는 $6.95, 12V 에서 320 mA, 작동 수압 0.02~0.8 MPa(최소 수압 필요), MCU 핀에서 직접 못 돌리고 TIP120/FET+환류 다이오드가 필요하다 — 원문: "$6.95" / "12V320 mA" / "Working Pressure: 0.02 Mpa - 0.8 Mpa" / "We suggest a TIP120 or N-Channel power FET with a 1N4001 kickback diode to drive this from a microcontroller pin." / "Normally, the valve is closed. When 12VDC is applied to the two terminals, the valve opens and water can push through." [S6]
12. AVIGUARD 는 Raspberry Pi 3B(YOLOv5) + Arduino UNO 가 SG90 서보 2개(팬·틸트)·레이저·부저·2채널 릴레이·12V 물펌프를 구동하는 구성으로, 액추에이터 조합의 참고 부품표가 된다 — 원문: "Raspberry Pi 3B" / "Arduino UNO" / "USB Webcam" / "2 × SG90 Servo Motors" / "Laser Module" / "Passive Buzzer" / "2-Channel Relay Module" / "12V DC Water Pump" / "YOLOv5 object detection model" [S7]

**(f) 공개 프로젝트의 결과·문제점**

13. AVIGUARD 는 FPS·정확도·실전 퇴치율 등 정량 결과를 전혀 싣지 않았고, 향후 과제로 추론 속도 개선을 든다(Pi 3B + YOLOv5 조합의 속도 한계 암시) — 원문: "Edge AI optimization for faster inference" [S7]
14. adamp87/pigeon 저장소 문서는 퇴치 동작을 콜백/주석 영상 출력으로만 정의하고 물리 액추에이터 사양은 없다 — 원문: "Output & Repellent Action (Pigeon Trigger Callback / Annotated Video)" [S1]

### 추론 (선택 — "추론:" 으로 시작)
- 추론: 감지 자체는 5주 안에 충분히 가능하다. COCO 사전학습 검출기에 `bird` 클래스가 있어 학습 없이 시작할 수 있고[S8], Pi 5 CPU 만으로도 YOLO 나노급이 NCNN 에서 ~67 ms(≈15 fps, 전후처리 제외)[S2], Coral 붙이면 ~26 ms[S1]다. 새가 실외기에 앉는 이벤트는 초 단위이므로 1~5 fps 면 충분하다.
- 추론: ESP32-S3 단독(약 $14 보드)은 FOMO 143 ms/7 fps 가 나오지만[S3] 96×96 입력·센트로이드 출력이라 실외기 위 작은 새의 오탐/미탐 검증이 필요하고, 비둘기 전용 데이터(수백 장)를 직접 모아 라벨링해야 한다 — 47장으로 F1 85% 사례[S3]를 보면 해커톤 기간 내 현실적이지만 정확도 상한이 낮다.
- 추론: 저전력 구조는 "PIR/mmWave OUT → ESP32-S3 RTC GPIO 웨이크업 → 카메라 추론 → 액추에이터" 로 공식 API 가 갖춰져 있으나[S4], LD2410 은 사람 감지용으로 규정돼[S5] 새(작고 체온 반응이 다른 대상)에 대한 트리거 신뢰성은 실측 없이는 보장 못 한다. PIR 도 마찬가지다. 트리거 없이 저프레임 상시 추론(Pi 5 유선 전원)이 해커톤에서는 더 안전한 선택이다.
- 추론: 액추에이터 중 물 분사는 부품이 싸고($6.95 밸브[S6]) 효과 기대치가 높지만, 수도 배관·최소 수압·12V 전원·방수·동절기 동파가 붙는다. 서보 반사판·부저는 AVIGUARD 부품표[S7] 수준으로 하루면 만든다. 공개 프로젝트 두 곳 모두 퇴치 효과의 정량 결과를 싣지 않았다[S1][S7] — 해커톤 산출물도 "감지 정확도" 는 수치화 가능하지만 "퇴치율" 은 실외 장기 관찰 없이는 주장 못 한다.
- 추론: 가장 큰 미지수는 (e) 실외기 환경이다. 상부 배기열·진동·방수·전원 인출 근거를 이번 조사에서 확보하지 못했으므로, 안전한 기본 설계는 "실외기 전기 계통에 손대지 않고 실내에서 USB/12V 어댑터 선을 빼며, 장치는 IP65 급 케이스에 넣고 실외기 위가 아닌 옆 벽/난간에 거치" 다. 태양광+배터리는 Pi 5(5V 5A 급 전원 요구, 보조 확인)에는 무리이고 ESP32-S3 딥슬립 구조에서만 성립한다.
